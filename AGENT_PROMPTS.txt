    "MJ":    0.277778,

    "Nm3":   None,

Implement:
  def normalize_to_kwh(value: float, unit: str) -> float:
    - Normalize unit string: strip whitespace, try exact key, then lowercase key.
    - If unit is "nm3" or "Nm3": raise ValueError("gas volume requires PCI factor
      — use normalize_gas_to_kwh()").
    - If unit not found: raise ValueError(f"unknown unit: {unit!r}").
    - Return value * factor.

  def normalize_gas_to_kwh(volume_nm3: float, pci_thermie_per_nm3: float) -> float:
    - Convert gas volume to kWh: volume_nm3 * pci_thermie_per_nm3 * 1.163
    - (PCI in thermie/Nm3, 1 thermie = 1.163 kWh)
    - Return the result.

─── CO2 EMISSION FACTORS ───────────────────────────────────────────────────────
  CO2_FACTORS_KG_PER_KWH = {
    "electricity": 0.2670,  # Tunisia grid 2024 (ANME reference)
    "natural_gas": 0.2010,  # 0.201 kg CO2/kWh gas (lower heating value)
    "fuel_oil":    0.2670,
    "coal":        0.3410,
    "default":     0.2670,
  }

  def estimate_co2_kg(normalized_kwh: float, energy_type: str = "default") -> float:
    - Look up factor from CO2_FACTORS_KG_PER_KWH (case-insensitive, strip spaces).
    - Fall back to "default" if energy_type not found.
    - Return normalized_kwh * factor.

─── ANOMALY DETECTION HELPERS ──────────────────────────────────────────────────
  SENSOR_THRESHOLDS = {
    "temperature":   {"min": 0.0,  "max": 60.0,  "spike_delta": 15.0},
    "humidity":      {"min": 0.0,  "max": 100.0, "spike_delta": 30.0},
    "voltage":       {"min": 0.0,  "max": 30.0,  "spike_delta": 5.0},
    "current":       {"min": 0.0,  "max": 5.0,   "spike_delta": 2.0},
    "power":         {"min": 0.0,  "max": None,  "spike_delta": 100.0},
    "vibration_rms": {"min": 0.0,  "max": 8.0,   "spike_delta": 2.0,
                      "alert_threshold": 3.0},
  }

  def check_sensor_anomaly(sensor_type: str, value: float,
                           prev_value: float | None = None
                           ) -> tuple[bool, str, float]:
    - Returns (is_anomaly: bool, reason: str, confidence: float 0-1).
    - Check: value out of range → is_anomaly=True, confidence=1.0
    - Check: spike (abs delta > spike_delta vs prev_value) → confidence=0.85
    - Check: vibration_rms > alert_threshold → is_anomaly=True, confidence=0.95
    - No anomaly → (False, "", 0.0)

PROMPT 4 — MQTT-to-HTTP Forwarder (scripts/mqtt_to_api.py)
================================================================================
Standalone script. Bridges hardware MQTT → our POST /api/telemetry.

Env vars (python-dotenv, load from .env at project root):
  MQTT_HOST        default "localhost"
  MQTT_PORT        default 8883 (int)
  MQTT_USERNAME
  MQTT_PASSWORD
  MQTT_TLS_ENABLED default "true" (parse "true"/"1" as True)
  MQTT_CA_CERT     optional path to CA cert
  API_BASE_URL     default "http://localhost:8000"

MQTT topic: "factory/alpha/edge_node_01/telemetry"

on_message logic:
  1. Parse JSON payload. Skip if malformed.
  2. timestamp_ms = packet.get("timestamp_ms", int(time.time()*1000))
  3. node_id: strip prefix "esp32s3_alpha_" from device_id, fallback to full id.
  4. Build list of dicts from packet["readings"], inject timestamp_ms + node_id.
  5. POST to f"{API_BASE_URL}/api/telemetry", timeout=5s.
  6. Print: f"[OK] seq={seq} readings={len} → {status_code}"
     or:   f"[ERR] seq={seq}: {exc}"

All exceptions caught — loop must never crash.
Use requests for HTTP, paho-mqtt for MQTT.
TLS: if enabled, client.tls_set(ca_certs=MQTT_CA_CERT or None).
__main__ block: load env, connect, loop_forever().

PROMPT 8 — Energy Forecasting (routers/forecast.py)
================================================================================
★ Part 2 bonus: short-term energy prediction. Simple but must return numbers.

Reference: database.py, utils/energy.py

Create routers/forecast.py and wire it in main.py as:
  app.include_router(forecast.router, prefix="/api", tags=["forecast"])

─── GET /forecast/scada ─────────────────────────────────────────────────────────
Query params: horizon_hours: int = Query(24, ge=1, le=168)
Algorithm (no ML library needed — pure numpy/statistics):
  1. Fetch last 7 days of scada_ledger rows ordered by timestamp.
  2. Extract normalized_kwh series.
  3. Compute 24-hour seasonal naive forecast:
       for each step h in 1..horizon_hours:
         predicted[h] = mean of historical values at the same hour-of-day
  4. If fewer than 24 historical points, fall back to overall mean.
  5. Return:
     {
       "method": "seasonal_naive_24h",
       "horizon_hours": int,
       "forecast": [
         {"offset_hours": h, "predicted_kwh": float, "confidence_interval_low": float,
          "confidence_interval_high": float}
       ],
       "mae_estimate": float   (mean absolute deviation of last 24h actuals vs naive)
     }
  Confidence interval: predicted ± 1 std deviation of residuals.

─── GET /forecast/telemetry/{sensor_id} ─────────────────────────────────────────
Query params: horizon_steps: int = Query(10, ge=1, le=60)
Algorithm:
  1. Fetch last 200 readings for sensor_id ordered by timestamp_ms.
  2. Compute simple exponential smoothing (alpha=0.3):
       s[0] = values[0]
       s[i] = alpha * values[i] + (1-alpha) * s[i-1]
  3. Forecast next N steps as the last smoothed value (flat forecast).
  4. Return {"method": "exponential_smoothing", "alpha": 0.3,
             "forecast": [{"step": i, "predicted_value": float}]}

Import only: statistics (stdlib), numpy optional (use stdlib math if not available).

PROMPT 9 — SCADA CSV Seeder (scripts/seed_scada.py)
================================================================================
Reference: models.py, database.py, utils/energy.py

Standalone CLI script. Usage: python scripts/seed_scada.py <path_to_csv>

CSV structure (SCADA export, French headers, messy):
  Rows 0–8   : metadata
  Row 6      : contains PCI factor, e.g. "PCI (thermie/Nm3): 9,082"
               (European decimal — comma is decimal separator)
  Row 9      : column headers  (header=9 in pandas)
  Row 10+    : numeric timeseries

Column detection (case-insensitive substring match):
  Timestamp  : "date" or "heure" or "time"
  Power kW   : "puissance" AND "brute"  → power_gross_kw
  Gas flow   : "debit" AND "gaz"        → gas_flow_nm3h

Steps:
  1. Read rows 0-8 with header=None, nrows=9, encoding="latin-1".
  2. Find PCI: regex r"[\d]+[,.][\d]+" over all cell string values.
     Replace comma→dot, cast to float. Default 9.082 if not found (warn).
  3. Read timeseries: header=9, encoding="latin-1". Drop fully-NaN rows.
  4. Detect column names (raise ValueError with clear message if not found).
  5. For each row:
     a. Parse timestamp (formats: "%d/%m/%Y %H:%M", "%Y-%m-%d %H:%M:%S",
        pd.to_datetime auto fallback).
     b. power_gross_kw = float(row[power_col]), skip if NaN.
     c. gas_flow_nm3h  = float(row[gas_col]),  skip if NaN.
     d. normalized_kwh = normalize_gas_to_kwh(gas_flow_nm3h, pci_factor)
        (import from utils.energy)
     e. raw_metrics = {k: v for k, v in row.items() if pd.notna(v)}
        Convert numpy scalars: use float(v) if isinstance v numpy.floating, etc.
     f. Build ScadaLedger ORM object.
  6. Bulk session.add_all(records), session.commit().
  7. Print "Seeded {N} records into scada_ledger."

After seeding, run a pass to create SCADA_ALARM events for rows where
normalized_kwh exceeds the 95th percentile (use statistics.quantiles):
  For each such row insert EventsAndAnomalies:
    source="SCADA_ALARM", severity="AVERTISSEMENT", acknowledged=False
    description="High energy consumption detected"
    context_data={"normalized_kwh": val, "threshold_95pct": threshold}

KNOWN CONSTRAINTS & GOTCHAS
================================================================================
- DISTINCT ON is PostgreSQL-only. Use sqlalchemy.text(), never ORM .all().

- node_id mapping: "esp32s3_alpha_edge_node_01" → "edge_node_01"
  (strip "esp32s3_alpha_" prefix). Hardcode this transform in the forwarder.

- SCADA CSV: French column names, latin-1 encoding, comma as decimal separator
  in the PCI factor row. PCI unit is thermie/Nm3, not kWh/Nm3. Factor 1.163
  converts thermie→kWh.

- normalized_kwh for SCADA = gas_flow_nm3h * pci_factor * 1.163
  This is hours-based (kWh per record interval). If records are every 10 min,
  divide by 6 to get per-interval kWh. Check interval from timestamp diffs.

- vibration_rms alert threshold = 3.0 g (hardware range 0–8 g, normal < 2 g).

- Documents.normalized_kwh and co2_emissions_kg are NOT NULL. The upload
  endpoint computes them from raw_value + raw_unit before insert, not from OCR.

- EventsAndAnomalies.acknowledged: always pass explicitly — never rely on DB
  default since the column is NOT NULL.

- CO2 factor for gas (SCADA/STEG_GAS): 0.201 kg CO2/kWh
  CO2 factor for electricity (STEG_ELECTRICITY): 0.267 kg CO2/kWh (Tunisia grid)

- For Docker: DATABASE_URL must use the Neon connection string directly.
  Do NOT try to add a postgres container — Neon is already provisioned.
