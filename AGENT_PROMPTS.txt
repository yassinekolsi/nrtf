PROMPT E — SCADA Excel Seeder (scripts/seed_scada.py)
================================================================================
Standalone CLI. Usage: python scripts/seed_scada.py <path_to_xlsx>

The Excel files have a NON-STANDARD layout:
  - Rows are field labels (column A), columns are time steps
  - Row 9:  Date values
  - Row 10: Time values (combine row9+row10 for timestamp)
  - Row 6:  Contains "PCI (thermie/Nm3): 9,082" (comma = decimal separator)
  - Data rows 11–61: field label in col A, values in cols B onward

Field label map (case-insensitive substring match):
  "debit" + "gaz"           → gas_flow_nm3h
  "puissance" + "brute"     → electrical_power_kw
  "rendement" + "electrique" → efficiency_electrical_pct
  "facteur de puissance"    → power_factor
  "voltage"                 → voltage_v
  "energie" + "alternateur" → electrical_energy_kwh
  "steg" + "achat"          → steg_purchase_kwh
  "steg" + "vente"          → steg_sale_kwh

Steps:
  1. Open with openpyxl read_only=True.
  2. Scan rows 1–9 for PCI value: regex r"[\d]+[,.][\d]+" over cell strings.
     Replace comma→dot, float. Default 9.082 if not found (warn).
  3. Read col A for field label map (rows 9–61).
  4. For each column B onward:
     a. timestamp = combine row9 date + row10 time → datetime
     b. Build readings dict from field label map
     c. gas_flow = readings.get("gas_flow_nm3h", 0)
     d. normalized_kwh = normalize_gas_to_kwh(gas_flow, pci_factor) / 6
        (divide by 6 because 10-min intervals → per-interval kWh)
     e. co2_kg = normalized_kwh * 0.202
     f. Insert ScadaLedger row with raw_metrics=readings dict
  5. Bulk insert, commit. Print "Seeded N records."
  6. After seeding: find rows where normalized_kwh > 95th percentile
     (use statistics.quantiles). Insert EventsAndAnomalies for each:
       source="SCADA_ALARM", severity="AVERTISSEMENT", acknowledged=False

Validation: run the seeder on any test xlsx. Hit GET /api/scada/summary — confirm
record_count > 0 and total_normalized_kwh is non-zero.

PROMPT G — Forecast Routes (routers/forecast.py) [BONUS]
================================================================================
+15 pts bonus. Simple math only — no ML library.

Create routers/forecast.py. Wire in main.py same as other routers.

GET /forecast/scada
  Query param: horizon_hours: int = Query(24, ge=1, le=168)
  1. Fetch last 7 days of scada_ledger rows ordered by timestamp.
  2. Group by hour-of-day. For each step h:
       predicted = mean of historical values at same hour-of-day mod 24
  3. Confidence interval: ± 1 std dev of residuals.
  4. Fallback to overall mean if < 24 historical points.
  5. Return:
     {
       "method": "seasonal_naive_24h",
       "horizon_hours": int,
       "forecast": [{"offset_hours": h, "predicted_kwh": float,
                     "ci_low": float, "ci_high": float}],
       "mae_estimate": float
     }

GET /forecast/telemetry/{sensor_id}
  Query param: horizon_steps: int = Query(10, ge=1, le=60)
  1. Fetch last 200 readings ordered by timestamp_ms.
  2. Exponential smoothing alpha=0.3: s[i] = 0.3*v[i] + 0.7*s[i-1]
  3. Forecast = last smoothed value × N steps (flat).
  4. Return {"method": "exponential_smoothing", "alpha": 0.3,
             "forecast": [{"step": i, "predicted_value": float}]}

Use only stdlib: statistics, math. numpy is optional.
